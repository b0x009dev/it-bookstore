## Демонстрационные страницы

Все демо проекта публикуются внутри `/it-store/`, отдельно для каждой практической работы.
Пока главная страница магазина не создана, `/it-store/` временно перенаправляет
на `/it-store/pr-03/tables.html` с кодом 302.

Практическая работа № 3:

- [Таблицы базы данных](http://201.34.159.85/it-store/pr-03/)
- [SQL-запросы и результаты](http://201.34.159.85/it-store/pr-03/queries.html)

Страницы формируются командой `npm run pr03:demo` в каталоге `pr-03/demo/`.
Ссылки между страницами относительные и работают при публикации в подкаталоге.
