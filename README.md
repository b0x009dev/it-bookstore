# База данных по предметной области<br>"Книжный магазин IT-литературы"

Репозиторий для демонстрации практических работ по дисциплине "Основы проектирования баз данных"

Выполнил: Мамаев Роман 01-25.ИСИП.ОД.11

## Демонстрационные страницы

Все демо проекта публикуются внутри `/it-store/`, отдельно для каждой практической работы.
Пока главная страница магазина не создана, `/it-store/` временно перенаправляет
на `/it-store/pr-03/tables.html` с кодом 302.

Практическая работа № 3:

- [Таблицы базы данных](http://201.34.159.85/it-store/pr-03/)
- [SQL-запросы и результаты](http://201.34.159.85/it-store/pr-03/queries.html)

Страницы формируются командой `npm run pr03:demo` в каталоге `pr-03/demo/`.
Ссылки между страницами относительные и работают при публикации в подкаталоге.

## Публикация через Nginx

Маршруты книжного магазина описаны в `deploy/nginx/it-store.conf`.
На сервере файл размещается в `/etc/nginx/snippets/it-store.conf` и подключается
внутри существующего блока `server` вместо прежних отдельных маршрутов
для `/tables` и `/queries`:

```nginx
include /etc/nginx/snippets/it-store.conf;
```

Старые адреса `/tables`, `/queries`, `/tables.html` и `/queries.html` перенаправляют
на страницы Практической работы № 3 внутри `/it-store/pr-03/`.
Адрес `/it-store/pr-03/` по умолчанию открывает `tables.html`.
Для следующих демо добавляются отдельные маршруты внутри `/it-store/`.
Неопубликованные пути в этом разделе возвращают 404.

Перед применением конфигурация проверяется командой `sudo nginx -t`,
затем перечитывается командой `sudo systemctl reload nginx` без остановки сервиса.
